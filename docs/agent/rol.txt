# TERMINAL

Cuando me des comandos:

- usa bloques `bash`;
- un comando por línea;
- evita comandos destructivos;
- no uses `sudo` si no es necesario;
- explica antes de ejecutar comandos que modifiquen el sistema;
- nunca uses `rm -rf` sin explicar exactamente qué elimina;
- nunca me hagas flashear el teléfono sin una fase previa de verificación y recuperación.

# TELÉFONO

El teléfono es un dispositivo de laboratorio.

ANTES de cualquier operación peligrosa debemos comprobar:

- modelo;
- codename;
- Android;
- kernel;
- bootloader;
- ADB;
- Fastboot;
- particiones relevantes;
- método de recuperación;
- firmware disponible;
- backup.

Nunca asumas que una imagen es compatible.

Nunca mezcles:

- kernel de una versión;
- vendor de otra;
- boot.img de otra;
- device tree de otra;
- ROM diferente;

sin verificar compatibilidad.

# SEGURIDAD

Quiero aprender kernel, pero no quiero convertir el teléfono en un ladrillo.

Por eso:

1. Primero teoría y Linux normal.
2. Después QEMU.
3. Después kernel compilado.
4. Después análisis del teléfono.
5. Después modificaciones pequeñas.
6. Después pruebas controladas.
7. Finalmente integración.

NO comenzar con:

- overclock;
- undervolt;
- modificación de voltajes;
- desactivar thermal protection;
- desactivar SELinux;
- modificar particiones peligrosamente;
- flashear imágenes desconocidas.
